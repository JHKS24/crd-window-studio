# CRD Window Studio

Chrome 원격 데스크톱으로 이 Mac에 접속할 때 나타나는 로컬 공유 표시창을 설정하는 macOS 앱입니다.

[English](README.md) | [빌드와 설치](BUILDING.ko.md) | [개인정보 처리](docs/PRIVACY.md)

원격 연결은 공식 Google 호스트가 담당하고, 별도의 접근성 도우미가 공유 창을 관찰해 사용자 설정을 적용합니다. Google이나 Apple과 제휴하거나 승인을 받은 제품이 아닌 독립 프로젝트입니다.

## 주요 기능

- 표시, 위치와 크기, 모양, 문제 해결로 나뉜 네이티브 SwiftUI 설정. 한국어와 영어, macOS의 화면 모드와 강조색 지원.
- 기본 바, 캡슐, 콤팩트, 카드, 상태 점 형상. 위치, 크기, 색상, 투명도, 모서리 설정 저장.
- 공유 창의 아무 곳이나 끌어서 옮깁니다(도우미가 직접 옮기므로 macOS가 창을 타일로 배열하거나 키우지 않으며, 시스템이 바꾼 크기는 저장하지 않고 되돌립니다). 상태 점의 색상, 지름, 바깥 여백을 따로 설정합니다.
- 어떤 모양에서든 공유 창의 아무 곳이나 두 번 클릭하면 창 가운데에 상태 점과 공유 중지 버튼이 있는 캡슐이 나타납니다. 공유 중지 버튼 밖을 두 번 클릭하면 원래 모양으로 돌아갑니다. 숨기는 방식은 두 가지입니다: 직접 숨길 때까지 두기(`stopRevealSeconds` 0), 또는 1~30초 뒤 자동으로 숨기기(기본값 5초). 공유 중지는 따로 한 번 더 클릭해야 눌립니다.
- 도우미가 그리는 공유 중지는 어디서나 알약 모양 버튼이며, 이름은 공유 중지 버튼 이름 설정을, 색은 공유 중지 버튼 모양 설정을 따릅니다: 빨간 버튼(흰 글자, 기본값) 또는 회색 버튼(붉은 글자). 두 모양은 크기와 누르는 영역이 같고, 프리셋에 함께 저장됩니다. 오른쪽 클릭이나 두 손가락 클릭은 창 메뉴를 열고, 왼쪽 클릭은 Control 키를 누른 채여도 클릭으로 남습니다.
- 위치 잠금과 크기 잠금은 설정 앱, 공유 창의 오른쪽 클릭 메뉴, 메뉴 막대 메뉴에 있습니다.
- 프리셋은 창 모양과 위치를 `config.json` 옆의 `presets.json`에 저장합니다. 설정 앱이나 도우미의 프리셋 메뉴에서 적용하며, 적용해도 표시 방식과 공유 창 바꾸기는 바뀌지 않습니다. 화면 밖으로 나가는 위치는 그 화면 안으로 맞춰 저장합니다. 설정 파일을 백업할 때 프리셋 파일도 함께 백업합니다.
- 설정 앱을 닫아도 남는 메뉴 막대 메뉴: 공유 창 바꾸기, 표시 방식, 가운데로 이동, 위치 잠금과 크기 잠금, 프리셋, 설정 열기, 공유 중지.
- 바깥을 클릭하거나 Escape를 누르면 닫히는 우클릭 메뉴, 실시간 미리보기, 동작 줄이기 지원.
- 변경 전후의 모양, 좌표, 크기, 상태 기록. 파일 크기는 최대 1 MiB이며, 도우미 실행 중에는 24시간이 지난 기록을 지웁니다. 도우미가 꺼져 있으면 만료된 기록은 다음 도우미 시작, `status`, `restore` 때 정리합니다. 도우미를 꺼도 24시간 이내 기록은 유지합니다.

표시 방식은 **꾸민 창**(`custom`, 기본값)과 **원래 공유 창**(`original`) 두 가지입니다. 처음 실행하거나 기본값으로 초기화하면 꾸민 창을 표시합니다. 저장된 숨김 모드(`hidden`)는 `custom`으로 불러옵니다.

## 책임 있는 사용

본인이 소유하거나 관리하는 Mac에서만, 그 Mac을 사용하는 사람들이 알고 동의한 상태에서 사용하세요. 현지 법을 따르세요.

이 앱은 로컬 Chrome 원격 데스크톱 알림 창만 바꿉니다. 세션이나 연결, Google 자체 조작 기능은 숨기지 않습니다. 도우미의 메뉴 막대 항목도 유지합니다. 원래 알림 창을 다시 보려면 **표시 방식**에서 **원래 공유 창**을 고르거나 **창 도우미 끄기**를 누르세요.

## 내려받기

[최신 릴리스](https://github.com/JHKS24/crd-window-studio/releases/latest)에서 DMG를 내려받습니다. macOS 14 이상의 Apple Silicon과 Intel Mac에서 실행됩니다.

Apple에 등록된 개발자의 앱이 아니라서 macOS가 게시자를 확인할 수 없고, 처음 열 때 앱을 막습니다. 아래 순서대로 한 번만 허용하면 됩니다. 소스는 모두 공개되어 있어서 누구나 읽어 보거나 직접 빌드할 수 있습니다.

1. DMG를 열고 CRD Window Studio를 Applications 폴더로 끌어다 놓습니다. 한국어 macOS에서는 앱 이름이 CRD 공유 창 설정으로 보입니다.
2. 옮긴 앱을 엽니다. macOS가 앱을 막으면 **휴지통으로 이동**이 아닌 **완료**를 누릅니다.
3. 시스템 설정 > 개인정보 보호 및 보안을 열고 아래쪽 보안까지 내려갑니다. CRD 공유 창 설정을 차단했다는 문구 옆의 **그래도 열기**를 누릅니다. 이 버튼은 앱을 열려고 한 뒤 약 1시간 동안 보입니다.
4. 나오는 창에서 **그래도 열기**를 한 번 더 누르고 Mac 로그인 암호를 입력합니다.
5. 표시 화면에서 **창 도우미 켜기**를 누릅니다. 명령어 라인 개발자 도구가 없으면 앱이 설치를 안내합니다. 설치를 마친 뒤 **창 도우미 켜기**를 다시 누릅니다.
6. macOS가 권한을 물으면 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용(macOS 27 이상에서는 기기 제어 및 데이터 접근)에서 CRD Window Host를 켭니다.

## 빌드와 실행

macOS 14 이상, Swift 5.9 이상, Apple Command Line Tools 또는 Xcode, Python 3가 필요합니다. 외부 Swift 패키지는 사용하지 않습니다.

```sh
./scripts/build.sh --all --universal
open "dist/CRD Window Studio.app"
```

CRD가 없어도 빌드와 미리보기를 사용할 수 있습니다. 실제 공유 창에 적용하려면 공식 Google 호스트를 먼저 설정한 뒤 [설치 안내](BUILDING.ko.md)를 따르세요. 도우미에는 손쉬운 사용 권한(macOS 27 이상에서는 기기 제어 및 데이터 접근)이 필요합니다. 화면 기록 권한은 요구하지 않습니다.

## 동작과 복구

도우미는 원본 호스트의 경로와 서명을 확인하고 접근성 구조에서 공유 창을 찾습니다. 원본 앱의 접근성 숨김 상태를 제어하며 실행 파일 패치나 Google 라이브러리 로드는 하지 않습니다. 공유 중지는 사용자가 누를 때 식별한 원본 버튼에 전달합니다.

관리기는 자체 사용자 LaunchAgent만 관리합니다. 설정은 Google 설치 폴더와 분리해 저장합니다. 원래 모양 선택, 도우미 정상 종료 또는 감지한 오류에서 원본 표시를 복구합니다. 강제 종료나 권한 철회 때는 복원이 늦어질 수 있습니다. [구조](docs/ARCHITECTURE.md)와 [복구 절차](BUILDING.ko.md)를 참고하세요.

## 확인한 범위

- arm64와 x86_64 빌드, 배포 대상 macOS 14 이상.
- 실행 확인 환경: Apple Silicon, macOS 27.0.1, CRD host 155.0.8059.19.
- 수동 확인 범위: 원격 연결, 조작, 재접속, 드래그.
- 네이티브 fixture, Swift 테스트, Python 모의 수명주기 검사와 패키징 검사를 제공합니다. 실행 명령은 [빌드 안내](BUILDING.ko.md#검사)에 있습니다.
- 다른 Mac에서의 실행과 향후 CRD 버전은 별도 확인이 필요합니다. 전체 Mac 재부팅은 검증하지 않았습니다.
- Windows 폴더는 읽기 전용 진단 소스와 포팅 지침입니다. 완성된 Windows 설정 백엔드가 아니며 Windows 빌드와 실행은 미검증입니다.

CRD의 접근성 구조가 바뀌면 작동하지 않을 수 있습니다. 대상을 확정하지 못하면 추측해서 조작하지 않고 원본 표시를 유지하거나 복구를 시도합니다. CRD 자체 입력 버그를 고치거나 Google 업데이트를 대신하는 앱은 아닙니다.

기본 로컬 빌드는 ad hoc 서명입니다. 로컬 서명 인증서는 [빌드 안내](BUILDING.ko.md)에 따라 선택할 수 있습니다. 릴리스 DMG에 들어 있는 앱도 ad hoc 서명이며 공증을 받지 않았습니다.

## 저장 데이터와 리소스

설정 경로는 `~/Library/Application Support/CRDWindowPatch/config.json`입니다. 로그에는 선택된 설정, 좌표, 상태 변화만 저장하며 계정, 접속 문구, 키 입력, 인증 정보는 기록하지 않습니다. 자체 텔레메트리나 네트워크 클라이언트는 없습니다. Google 호스트의 데이터 처리는 별개입니다. 자세한 범위는 [Privacy](docs/PRIVACY.md)에 정리했습니다.

원격 연결 중 설정 앱을 닫고 측정한 20초 유휴 구간의 도우미 사용량은 평균 CPU 0.05%, RSS 약 99 MiB입니다. 특정 구간의 관찰값이며 성능 보장이나 CRD 인코딩 비용이 아닙니다.
