공유 알림 창을 작은 점 하나로

CRD Window Studio는 Chrome 원격 데스크톱이 Mac에 띄우는 공유 알림 창의 모양과 크기, 자리를 바꿔 줍니다. 작은 점 하나로 줄여 두었다가 두 번 클릭하면 공유 중지 버튼이 나옵니다.

만든 이유

Chrome 원격 데스크톱으로 Mac에 접속하면 화면에 공유 알림 창이 뜹니다. 이 창은 접속을 끊을 때까지 사라지지 않습니다.

그래서 알림은 남겨 두고, 모양과 자리를 제가 정할 수 있게 만들었습니다. 지금은 화면 오른쪽 위에 작은 점 하나만 띄워 둡니다.

기능

모양 다섯 가지

기본 바, 캡슐, 콤팩트, 카드, 상태 점 가운데 하나를 고릅니다. 크기와 모서리 둥글기를 따로 정하려면 직접 지정을 고릅니다.

두 번 클릭하면 열리는 점

상태 점은 작은 동그라미 하나입니다. 두 번 클릭하면 옆으로 늘어나면서 공유 중지 버튼이 나오고, 정해 둔 시간이 지나면 다시 점으로 접힙니다. 시간은 1초에서 30초 사이로 정하거나, 직접 접을 때까지 열어 둘 수 있습니다.

원하는 자리에

가운데, 상단 가운데, 하단 가운데 중에 고르거나 직접 지정에서 좌표를 넣습니다. 창을 끌어서 옮기면 그 자리가 저장됩니다. 모니터가 여러 대면 띄울 화면도 고를 수 있습니다.

메뉴 막대

메뉴 막대 아이콘에서 지금 상태를 확인합니다. 메뉴에서 공유 창 바꾸기를 켜고 끄거나 표시 방식, 잠금, 프리셋을 바꾸고, 가운데로 이동과 공유 중지도 바로 누릅니다.

잘못 눌리지 않는 공유 중지

점을 여는 두 번 클릭이나 메뉴를 닫는 클릭은 공유 중지로 이어지지 않습니다. 따로 한 번 눌러야 동작하고, 누르면 Chrome 원격 데스크톱의 원래 공유 중지 버튼이 눌립니다.

위치 잠금과 크기 잠금

자리와 크기를 정했으면 잠가 둡니다. 잠근 동안에는 잘못 끌거나 모서리를 잡아당겨도 움직이거나 크기가 바뀌지 않습니다.

색과 테두리

라이트, 다크, 자동 중에 고르고, 강조 색상은 시스템이나 여덟 가지 색 중에서 고릅니다. 배경 색상과 글자 색상, 모서리 둥글기, 테두리 두께, 글자 크기, 불투명도, 그림자도 바꿀 수 있습니다.

원래 창으로 바로

표시 방식을 원래 공유 창으로 바꾸거나 창 도우미를 끄면 원래 알림 창이 곧바로 돌아옵니다. 도우미가 꺼질 때도 원래 창부터 되돌려 놓고 끝납니다.

한국어와 영어

설정 앱과 메뉴는 한국어와 영어로 나옵니다. macOS 언어 설정을 따릅니다.

기록은 이 Mac에만

설정과 창 상태가 바뀐 기록은 이 Mac에만 남고 24시간이 지나면 지워집니다. 파일은 1MB를 넘지 않고, 어디로도 보내지 않습니다.

설정 앱

설정은 네 화면으로 나뉩니다. 바꾼 값은 바로 적용되고, 따로 저장 버튼을 누를 필요가 없습니다.

실제 크기 미리보기 창을 띄우면 그 창을 옮기고 늘리는 대로 자리와 크기가 저장됩니다.

동작 방식

  1. 설정 앱에서 바꾼 값은 config.json 파일 하나에 저장됩니다.
  2. 창 도우미는 launchd가 관리하는 작은 백그라운드 앱입니다. 이 파일을 지켜보다가 바뀌면 곧바로 반영합니다.
  3. 도우미는 손쉬운 사용 권한(macOS 27에서는 기기 제어 및 데이터 접근)으로 Chrome 원격 데스크톱의 공유 알림 창을 찾습니다. 창 구조가 정확히 맞을 때만 원래 창을 가리고 그 자리에 새 창을 띄웁니다.
  4. 새 창의 공유 중지 버튼은 원래 창의 공유 중지 버튼을 대신 누릅니다. 연결을 끊는 일은 Chrome 원격 데스크톱이 직접 합니다.
  5. Chrome 원격 데스크톱의 파일은 고치지도 바꾸지도 않습니다. 화면 기록 권한도 쓰지 않습니다.

설치

DMG 파일을 내려받아 설치합니다. macOS 14 이상이 필요하고, 이 Mac에 Chrome 원격 데스크톱이 설정되어 있어야 합니다.

DMG 내려받기

Apple에 등록된 개발자의 앱이 아니라서 macOS가 게시자를 확인할 수 없고, 처음 열 때 앱을 막습니다. 아래 순서대로 한 번만 허용하면 됩니다. 소스는 모두 공개되어 있어서 누구나 읽어 보거나 직접 빌드할 수 있습니다.

  1. DMG를 열고 CRD Window Studio를 Applications 폴더로 끌어다 놓습니다. 한국어 macOS에서는 앱 이름이 CRD 공유 창 설정으로 보입니다.
  2. 옮긴 앱을 엽니다. macOS가 앱을 막으면 휴지통으로 이동이 아닌 완료를 누릅니다.
  3. 시스템 설정 > 개인정보 보호 및 보안을 열고 아래쪽 보안까지 내려갑니다. CRD 공유 창 설정을 차단했다는 문구 옆의 그래도 열기를 누릅니다. 이 버튼은 앱을 열려고 한 뒤 약 1시간 동안 보입니다.
  4. 나오는 창에서 그래도 열기를 한 번 더 누르고 Mac 로그인 암호를 입력합니다.
  5. 앱이 열리면 표시 화면에서 창 도우미 켜기를 누릅니다. 명령어 라인 개발자 도구가 없으면 앱이 설치를 안내합니다. 설치를 마친 뒤 창 도우미 켜기를 다시 누릅니다.
  6. macOS가 권한을 물으면 시스템 설정 > 개인정보 보호 및 보안 > 기기 제어 및 데이터 접근에서 CRD Window Host를 켭니다. macOS 26까지는 같은 곳의 손쉬운 사용 항목입니다.

소스에서 빌드하기

소스에서 직접 빌드할 수도 있습니다. Xcode 또는 Command Line Tools(Swift 5.9 이상)와 Python 3이 필요합니다.

git clone https://github.com/JHKS24/crd-window-studio.git
cd crd-window-studio
./scripts/build.sh --all --universal
open "dist/CRD Window Studio.app"

앱을 ~/Applications처럼 옮기지 않을 자리에 두고, 표시 화면에서 창 도우미 켜기를 누릅니다. macOS가 권한을 물으면 시스템 설정 > 개인정보 보호 및 보안 > 기기 제어 및 데이터 접근에서 CRD Window Host를 켭니다. macOS 26까지는 같은 곳의 손쉬운 사용 항목입니다.

빌드 옵션과 명령줄로 설치하는 방법은 BUILDING 문서에 정리해 두었습니다.

Shrink the sharing notice to a single dot

CRD Window Studio changes the shape, size and position of the sharing notice Chrome Remote Desktop shows on a Mac. Keep it as a small dot, and double-click it when you want the Stop Sharing button.

Why I made it

When you connect to a Mac with Chrome Remote Desktop, a sharing notice appears on the screen. It doesn't go away until you disconnect.

So the notice stays, and I choose its shape and where it sits. Mine is a small dot in the top right corner now.

Features

Five shapes

Pick Default Bar, Capsule, Compact, Card or Status Dot. Choose Custom to set the size and corner radius yourself.

→

A dot that opens

The status dot is one small circle. Double-click it and it stretches into a capsule with a Stop Sharing button, then folds back after the delay you choose, anywhere from 1 to 30 seconds. You can also keep it open until you close it yourself.

Wherever you want it

Choose Center, Top Center or Bottom Center, or select Custom to enter coordinates. Drag the window and its new spot is saved. With more than one display, choose which one it appears on.

Menu bar

The menu bar icon shows the current state. From its menu you can switch Replace Sharing Window on or off, change the display mode, center the window, toggle the locks and apply presets. Stop Sharing is there too.

Stop Sharing that waits for you

The double-click that opens the dot and the click that closes a menu never reach Stop Sharing. It takes a separate single click, and that click presses Chrome Remote Desktop's own Stop Sharing button.

Lock Position and Lock Size

Lock the position and size once they're set. While locked, a stray drag or a pulled corner won't move or resize the window.

Colors and borders

Choose Light, Dark or Auto, and set the accent color to System or one of eight colors. Background and text colors, corner radius, border width, text size, opacity and shadow can be changed too.

The original, one switch away

Set the display mode to Original Sharing Window or turn the window helper off, and the original notice comes back right away. The helper also puts it back before it quits.

Korean and English

The settings app and the menus are in Korean and English, following your macOS language.

Logs stay on this Mac

Changes to settings and window state are logged on this Mac only, kept for 24 hours and capped at 1 MB. Nothing is sent anywhere.

The settings app

Settings are split across four pages. Changes apply as you make them, so there's no Save button.

Open the real-size preview, and the position and size follow that window as you move and resize it.

How it works

  1. Everything you change in the settings app is saved to one config.json file.
  2. The window helper is a small background app run by launchd. It watches that file and applies changes right away.
  3. With the Accessibility permission (Device Control and Data Access on macOS 27), the helper looks for Chrome Remote Desktop's sharing notice. Only when the window's structure matches exactly does it hide the original and show its own window in that place.
  4. The Stop Sharing button in the new window presses the original button for you. Chrome Remote Desktop ends the session itself.
  5. No Chrome Remote Desktop files are changed or replaced, and no screen recording permission is used.

Install

Download the DMG and install it. You'll need macOS 14 or later and Chrome Remote Desktop already set up on the Mac.

Download the DMG

The app isn't from a registered Apple developer, so macOS can't confirm the publisher and blocks it the first time you open it. Allow it once with the steps below. The whole source is public, so anyone can read it or build it.

  1. Open the DMG and drag CRD Window Studio to the Applications folder.
  2. Open the app from the Applications folder. When macOS blocks it, click Done, not Move to Trash.
  3. Open System Settings > Privacy & Security and scroll down to Security. Next to the message that CRD Window Studio was blocked to protect your Mac, click Open Anyway. The button appears for about an hour after you try to open the app.
  4. Click Open Anyway once more in the dialog that appears, then enter your Mac login password.
  5. When the app opens, click Turn On Window Helper on the Visibility page. If the command line developer tools aren't installed, the app asks you to install them. Install them, then click Turn On Window Helper again.
  6. When macOS asks, turn on CRD Window Host in System Settings > Privacy & Security > Device Control and Data Access. On macOS 26 and earlier it's under Accessibility in the same place.

Build from source

You can also build it from source. You'll need Xcode or the Command Line Tools (Swift 5.9 or later) and Python 3.

git clone https://github.com/JHKS24/crd-window-studio.git
cd crd-window-studio
./scripts/build.sh --all --universal
open "dist/CRD Window Studio.app"

Move the app somewhere it will stay, such as ~/Applications, and click Turn On Window Helper on the Visibility page. When macOS asks, turn on CRD Window Host in System Settings > Privacy & Security > Device Control and Data Access. On macOS 26 and earlier it's under Accessibility in the same place.

Build options and command-line setup are in BUILDING.md.
